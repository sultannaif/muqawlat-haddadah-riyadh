# مقاولات وحداده — الرياض

موقع عربي سريع لخدمات الحدادة والمظلات والبرجولات في الرياض، مع تواصل مباشر عبر واتساب والاتصال.

## التشغيل والبناء

يتطلب Node.js فقط، دون أي مكتبات خارجية:

```bash
npm run build
```

تُنتج النسخة الجاهزة للنشر داخل مجلد `dist`.

## تحديث رابط الموقع

عند ربط نطاق أو رابط استضافة نهائي، عيّن المتغير `SITE_URL` أثناء البناء حتى تُنشأ الروابط الأساسية وخريطة الموقع بالعنوان الصحيح.
